Privacy Policy

Last updated: November 12, 2026

This policy covers "World of Curiosity Bot", a private tool used only by the owner of the YouTube channel World of Curiosity Stories.

What the tool does

The tool uses the YouTube Data API to upload videos, set titles, descriptions and thumbnails, and read public statistics for the owner's own channel. It also reads publicly available video information to research topics.

Data we access

  • Only the channel owner signs in to the tool. No other person's Google account is accessed.
  • The access token is stored only on the owner's own computer or server and is never shared or sold.
  • The tool does not collect, store or share personal data about viewers.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

For questions, contact the channel through its YouTube About page.
